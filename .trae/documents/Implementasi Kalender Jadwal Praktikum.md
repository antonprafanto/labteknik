Berikut adalah rencana kerjanya:

### 1. Instalasi & Setup FullCalendar 📅
- Menginstal library `@fullcalendar` via NPM.
- Mengintegrasikan FullCalendar ke dalam aset frontend (`app.js`).

### 2. Backend & API Jadwal 🔄
- Membuat komponen Livewire baru `Schedules\Calendar` khusus untuk tampilan kalender.
- Menyiapkan logika backend untuk mengubah data jadwal dari database menjadi format JSON yang bisa dibaca kalender.
- Menambahkan filter laboratorium agar kalender bisa menampilkan jadwal per ruangan.

### 3. Integrasi Tampilan (Frontend) 🖥️
- Membuat view kalender yang interaktif.
- Menambahkan fitur:
    - **Klik Tanggal**: Membuka modal untuk tambah jadwal baru di tanggal tersebut.
    - **Klik Jadwal**: Melihat detail atau mengedit jadwal.
    - **Navigasi**: Pindah bulan/minggu dengan mudah.

### 4. Finalisasi & Pengujian 🧪
- Memastikan tidak ada bentrok jadwal saat input via kalender.
- Memastikan tampilan responsif di mobile.
